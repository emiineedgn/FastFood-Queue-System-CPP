# FastFood-Queue-System-CPP
A C++ implementation of a FIFO queue data structure to manage fast-food restaurant orders.


# Fast Food Order Management System (C++ Queue) 🍔

🌍 *[🇹🇷 Türkçe okumak için aşağıya kaydırın (Scroll down for Turkish)]

A terminal-based fast food order management system developed in C++ to demonstrate the practical implementation of the Queue (First-In-First-Out / FIFO) data structure. The project manages the flow of incoming orders and simulates the preparation and delivery process.

## ⚙️ Features
* **Add Order:** Accepts customer name and the ordered item (e.g., hamburger, coffee)[cite: 7], pushing it to the back of the queue.
* **Prepare Order:** Pops the order from the front of the queue, finalizing the delivery[cite: 7].
* **List Orders:** Traverses and displays all currently waiting orders without altering the original queue[cite: 7].
* **Order Count:** Returns the exact number of pending orders[cite: 7].

## 🛠️ Technologies & Execution
* Language: `C++`
* IDE: `Dev C++` compatible[cite: 7]
* Libraries used: `<iostream>`, `<queue>`, `<string>`

# 🇹🇷 Türkçe Sürüm

Kuyruk (Queue - İlk Giren İlk Çıkar / FIFO) veri yapısının pratik kullanımını göstermek amacıyla C++ ile geliştirilmiş terminal tabanlı bir fast food restoranı sipariş yönetim sistemidir[cite: 7]. Proje, gelen siparişlerin akışını yönetir ve hazırlık/teslimat süreçlerini simüle eder.

## ⚙️ Özellikler
* **Sipariş Ekleme:** Müşteri adı ve sipariş detayını (örn. hamburger, kahve) alarak kuyruğun sonuna ekler[cite: 7].
* **Sipariş Hazırlama:** Kuyruğun başındaki ilk siparişi çıkarır ve "siparişi hazırlandı ve teslim edildi" onayı verir[cite: 7].
* **Siparişleri Listeleme:** Kuyruğun orijinal yapısını bozmadan mevcut tüm bekleyen siparişleri sırayla ekrana yazdırır[cite: 7].
* **Bekleyen Sipariş Sayısı:** Kuyrukta bekleyen siparişlerin anlık toplamını gösterir[cite: 7].
